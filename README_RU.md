# ForgeCheck

**Простая и быстрая проверка безопасности Linux.** Одна команда, понятные результаты и рекомендации. Без облачной учётной записи, удалённого сканирования и автоматического изменения системы.

## Что такое ForgeCheck?

ForgeCheck — локальный аудит конфигурации и безопасности Linux, написанный на Rust. Он проверяет выбранные настройки, объясняет результаты простым языком и предлагает, что стоит перепроверить.

**Наша цель — полезная информация о безопасности без сложного интерфейса.**

### Главное

- Одна команда для запуска.
- Понятные уровни: PASS, INFO, LOW, MEDIUM, HIGH, CRITICAL.
- Отчёты в терминале, JSON и Markdown.
- Только чтение: программа не меняет настройки системы.
- Локальная работа: отчёты не отправляются на сервер.
- Быстрая сборка на Rust, без сторонних Rust-зависимостей.

## Быстрый старт

### Скачать готовую версию

1. Открой [ForgeCheck Releases](https://github.com/abduforge/forgecheck/releases/latest).
2. Скачай архив для Linux. Для большинства ПК Intel/AMD нужен `x86_64`.
3. Распакуй архив.
4. В распакованной папке выполни:

   ```bash
   ./install.sh
   ```

5. Открой новый терминал и выполни:

   ```bash
   forgecheck
   ```

Программа устанавливается в `~/.local/bin`, права администратора не нужны.

### Собрать из исходников

Нужны Linux и Rust 1.85 или новее.

```bash
git clone https://github.com/abduforge/forgecheck.git
cd forgecheck
cargo test --all-targets
cargo build --release
./target/release/forgecheck
```

## Что проверяется

- Права доступа к `/etc/passwd` и `/etc/shadow`.
- Наличие дополнительных аккаунтов с UID 0.
- Некоторые важные настройки SSH.
- Локальный TCP-порт 22, если доступна утилита `ss`.
- Статус UFW, firewalld, nftables или iptables, если они установлены.
- Некоторые настройки сетевого стека ядра Linux.
- Права каталогов `/etc` и `/etc/ssh`.

Если инструмент или настройка недоступны, ForgeCheck сообщает об этом. Недоступная проверка не считается успешной.

## Команды

```bash
forgecheck                         # обычная проверка
forgecheck scan --json             # JSON
forgecheck scan --markdown         # Markdown
forgecheck scan -o report.md --markdown
forgecheck checks                  # список проверок
forgecheck doctor                  # диагностика окружения
forgecheck --version               # версия
forgecheck --help                  # справка
```

## Безопасность и ограничения

ForgeCheck не выполняет эксплуатацию уязвимостей, не сканирует удалённые устройства и публичные IP-адреса, не меняет настройки и не удаляет файлы. Это не антивирус и не полноценный пентест-инструмент. Результат PASS не гарантирует абсолютную безопасность.

Проект экспериментальный и пока не проходил независимый аудит безопасности. Подробности: [SECURITY.md](SECURITY.md).
